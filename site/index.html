A LITTLE MORE CONTEXT

Good questions.
Clear answers.

What is Cosigna?+

Cosigna is one product for agent permissions, approvals, controlled transaction execution, and recovery. The gateway is its foundation; the console and assistant are interfaces above it.

Can an agent approve its own payment?+

No. The current purchase gateway requires an owner to approve the exact quote. A model proposal, voice request, budget, or workflow message is not approval.

Can I use it with real money today?+

The available purchase path is a development sandbox. Production identity, signed transaction permits, authorization consolidation, and a supported live connector remain release gates.

Where does the voice assistant fit?+

The assistant is an application of the same transaction foundation. Its local voice-ordering prototype uses the sandbox; general merchant access and pickup integrations are still in development.
