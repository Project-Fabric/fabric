# Contributing

Ledgerly feeds the company's financial statements, so in-scope code (see the README) is
under SOX change management:

1. Every change to in-scope code is linked to a change record and approved by someone other
   than its author before it is merged.
2. Tests pass, including the finance controls run in CI.
3. Changes that affect amounts (rounding, tax, recognition) are reviewed by Finance.

AI coding agents may work on this repository. Their changes follow the same rules, and the
person who prompted the agent is not its approver.
